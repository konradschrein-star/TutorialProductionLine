# Private review guide

Use http://127.0.0.1:13118/tutorial-studio while the private SSH forward is running.
This is the isolated VPS2 installation, not Content Forge or Omar's production.

## Suggested review order

1. **All tutorials:** search existing English originals and open the exact tutorial.
2. **Thumbnails:** inspect the English canvas at working size, text legibility,
   layer controls, asset selection, and localized drafts. Existing reference and
   character assets remain preserved. Final channel-specific assets can follow.
3. **Languages / Final review:** inspect language flags, statuses, exact tutorial
   selection, and full-size image previews. Do not approve historical work merely
   to test navigation.
4. **Delivery & Uploads:** review the manual path. Automatic uploader destinations
   are yours to configure later, independently for each channel.
5. **Settings / Channels:** there is no fixed channel network size. One or twenty
   channels are valid. The optional uploader is excluded from the core setup count;
   saved credentials are not described as verified live connections.

## Deliberately not activated

- AI image generation, workers, automatic publication, and media eviction.
- Public DNS/team migration; existing production sites remain unchanged.
- Uploader destinations and VeoForge hosting, which the owner deferred.

## Still engineering work, not just configuration

- VeoForge needs the shared editable connection resolver in web and workers;
  saving a token alone does not update environment-driven clients.
- The audited CDP uploader supports private/unlisted exchange, but not yet the
  Studio scheduled-publication protocol or downstream emergency-stop contract.
- Keyword Tool frontend integration remains unverified after a denied local
  startup. Do not route around that execution policy.
- A representative full VA production pilot is still needed before team cutover.

Historical English recovery remains separate. Missing translated versions can be
regenerated, but unknown-language files must not be assumed to be translations.
