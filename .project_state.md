## 1. Project Overview & Architecture Direction

* **Goal:** Replace brittle/compromised legacy YouTube automators with a reliable, streamlined Tutorial Production Line for creators and VAs.
* **Core Architecture Decision:**
  * **Old codebase (`rhyleematte/Youtube-Automation`):** Deprecated & rejected for code/infrastructure due to critical security leaks (private SSH key & live session cookies in Git), hallucinated APIs (fake Mistral TTS), fake metrics (`Math.random()`), and brittle headless Playwright automation.
  * **UX Pattern Retained:** High-velocity 5-step production wizard (*Idea -> Script -> Audio -> Video -> Review/Queue*).
  * **Backend Integration:** Backed by **Keyword Tool v2** (10,066 screened keywords) and **Stealth Uploader** architecture (human-paced, reach-preserving distribution).
