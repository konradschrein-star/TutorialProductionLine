## 🎯 Architecture & Factory Modules
* **Aesthetics:** [Taste-Skill](https://github.com/Leonxlnx/taste-skill) principles + DaVinci Resolve Workstation dark mode (`#0a0c10`) + Notion/Linear light mode (`#ffffff`). Pure monochrome contrast, zero yellow accents.
* **Core Factory Features:**
  1. **5-Step Conveyor Wizard (`/`):** Idea/Claimed Pool ➔ Spoken Script ➔ Neural Voice (Fish/ElevenLabs) ➔ Screen Recording (In-Browser WebRTC capture) ➔ 1-Click Batch 5+ Multi-Language Localization Engine.
  2. **Teleprompter Pro:** Fullscreen rehearsal prompter with auto-scroll and mirror reflection.
  3. **Thumbnail Studio Pro (`/thumbnails`):** DaVinci inspector-style canvas editor with 100+ persona images, 100+ software logos, 110+ symbols, AI brief extraction, and 1-Click 10-Language ZIP Export.
  4. **Keyword Intelligence Hub (`/keywords`):** 10,066 DeepSeek-screened HOW_TO topics with real volumes, software filtering, and 1-click conveyor loading.
  5. **Floating Upload Queue (`RecordingUploadQueue`):** Non-blocking background chunked upload manager.
  6. **Finished Videos & Stealth Queue (`/finished`):** Video playback modal, single & batch manifest JSON exporter for Dolphin Anty.
  7. **Hetzner Server Backend (`server/`):** Express API with 16 GB RAM disk storage (`/mnt/ramdisk`), FFmpeg stream-copy remuxer, and multi-language workers.
