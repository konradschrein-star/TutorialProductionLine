## 🎯 Architecture & Verified Systems
* **Zero-Dependency Standalone Workstation:** Completely decoupled from external monorepos / ContentForge. Ready for VA/clients to pull and run with instant setup.
* **Full-Featured Thumbnail Studio (`/thumbnails`):**
  - Identical full feature set from the original thumbnail app, equipped with client-customizable brand references instead of fixed personal references.
  - Complete asset catalog: 71 real app logos (`app_logos_png`), 111 colored symbols (`bulk_symbols_110_colored`), 4 HD backgrounds, and 10 language personas.
  - Custom Brand References tab: Upload and categorize custom persona face cutouts, company logos, product badges, and backgrounds.
  - Rich typography engine: Font family picker (Impact, Anton, Montserrat, Bebas Neue, Arial Black), font size (24-120px), text color, stroke color, stroke width (0-20px), rotation, and opacity.
  - Channel brand preset template saver (`Bookmark` icon) for 1-click styling.
  - 10-language batch pack ZIP exporter & single HD PNG export (2.4x pixel ratio).
  - 16:9 HD & 9:16 Shorts aspect ratio switching.
* **Team & Account Management (`Settings.tsx`):**
  - Full CRUD operations for Administrator, Manager, and Virtual Assistant operator accounts.
  - Preconfigured team: **Omar (Admin)**, **Jeen (Admin)**, **Nalu (Tutorial VA)**, and **Lorraine (Tutorial VA)**.
  - Active operator defaults to **Nalu** (`nalu@tutorialstudio.com`) with automated self-healing migration from legacy placeholders.
  - Granular channel access controls, software specialization assignments (`assignedSoftwares`), and 1-click active user switching.
  - Zero external code / AI needed—pure in-app UI with persistent local state.
* **Workstation Operator Guide & Architecture Manual (`/guide`):**
  - Interactive multi-section manual covering System Overview, Keyword Ingest, 5-Step Conveyor, Studio Pipeline, Thumbnail Studio, Google Drive Setup, Account Management, Localization, and Hotkeys.
* **Defensive Fault-Tolerance & Error Handling:**
  - `StorageService` resilient in-memory backing fallback on `QuotaExceededError` or disabled/corrupt `localStorage`.
  - `AIService` `AbortController` 15-second timeout guards on all fetch requests + regex JSON extraction for markdown responses.
  - `GoogleDriveService` directory traversal sanitization (`..` prevention) and dangerous filename character cleansing.
  - `MetricsService` safe date and zero-division fallbacks.
  - `ErrorBoundary` UI crash containment with "Reload", "Copy Error Stack", and "Clear Cache & Reset" actions.
* **Test Suite:** 55 Passing Unit & Component Tests across 12 test suites (`npm test` via Vitest). Production build verified (`tsc && vite build`).
* **Onboarding & Setup Wizard:** 4-step guided setup modal for VA Profile, Custom Channels, AI Keys, and Google Drive destination paths.
* **Google Drive Cloud Folders & Performance Tracking Suite (`FinishedVideos.tsx`):**
  - Built to Shane's ("Big Boss") exact operational specifications.
  - Dedicated Active Creator Folders for every YouTube channel with direct Google Drive links and copy-path actions.
  - Master Archive Folder for completed project tracking.
  - Daily Creator Performance Tracker table with 1-click **Export Tracker Sheet (CSV)**.
  - Video Asset Index table with 1-click **Export Video Asset Index (CSV)**.
  - Live Cloud Delivery audit stream.
* **High-Contrast Single-Person Thumbnail Directive:**
  - Enforced in all auto-generated thumbnail prompts (`CreatorWizard.tsx`, `ThumbnailStudio.tsx`, `aiService.ts`, `prompt-builder.ts`, `deepseek-prompt.ts`):
    *"Text must be black for contrast and have no mistakes. Only one person on the Thumbnail"*.
* **Onboarding & Setup Wizard:** 4-step guided setup modal for VA Profile, Custom Channels, AI Keys, and Google Drive destination paths.
* **Multi-Language Localization Factory (`LocalizationModal` & `LocalizePanel`):** Standard 5-language launch set (🇩🇪 German, 🇫🇷 French, 🇪🇸 Spanish, 🇯🇵 Japanese, 🇰🇷 Korean). "Translate everything missing" strictly translates only into active standard languages to prevent runaway token spend. Includes standard language settings, 1-click backfilling across completed videos, and individual non-standard language on-demand translation.
* **Recording Studio & Upload Stability:** Translation child jobs are strictly partitioned from the VA's recording studio list (`isNull(source_job_id)`) so translation batches never flood the recording list or disable VA recording uploads.

* **Google Drive Automated Cloud Delivery Engine:** Full configurable folder structure (`{channel}/{year}_{month}/{topic_slug}/`), custom file naming rules (`{date}_{title}_{lang}.mp4`), connection test ping, automated dispatch on splice completion, backend REST API endpoints (`/api/drive/test`, `/api/drive/upload`), and live delivery audit trail.
* **Standalone Studio Pipeline (`/studio`):** Native pipeline workstation with real-time job states, speed slider (1.0x - 1.6x) with unique FPS indicator (`ASSUMED_CAPTURE_FPS / speed`), multi-stage retries (script, audio, splice), video take preview player, and in-place script editor drawer with instant audio re-synthesis.
* **Supercharged Keyword Intelligence Hub (`/keywords`):** CSV / TSV import dropzone with auto-column detection & deduplication, CSV export, search volume range filters (>10k, >5k, >1k, <1k), competition filters, bulk channel assignments, and bulk deletion.
* **Dynamic Channel Management (`/settings`):** Add, edit, delete custom channel profiles with custom niches, badge colors, neural voice bindings, Google Drive target directories, and custom AI prompt rules.
* **Production Velocity & Metrics Dashboard (`/metrics`):** Real-time analytics on total tutorials produced, watch time generated, 7-day velocity chart, channel distribution, and VA throughput.
* **Aesthetics & Dual Theme:** [Taste-Skill](https://github.com/Leonxlnx/taste-skill) principles: DaVinci Resolve Workstation dark mode (`#0a0c10`) + Notion/Linear high-contrast light mode (`#fbfbfb` / `#ffffff`). Pure monochrome contrast.
